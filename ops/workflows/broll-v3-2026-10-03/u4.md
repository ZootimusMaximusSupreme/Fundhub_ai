# U4 manifest — ProofChips · ItemCount

**Status: done.** Both clips render to MP4. Both previews exist. Typecheck is clean for my files. I looked at the frames (start, middle, hero, last), at the safe-zone overlay, and at the edge cases listed below.

**Style.** I built these in tasteful 3D, following the coordinator's update ("3D is allowed and wanted, only money is banned"). They use the kit's depth helpers: `Stage3D` (a gentle camera drift, set to 0.8), `Layer`, `P3D`, `CARD_EDGE` and `cardShadow`. Thickness comes from real plates stacked behind each face. Nothing comes from `money.tsx`, and there are no approval screenshots. Springs use the kit's no-bounce `enter` / `fadeUp`. The accent is blue `#3D86F0` and the font is Inter.

## 2. ItemCount (simple HiddenDataPoints)

| | |
|---|---|
| Composition id | `ItemCount` |
| File | `marketing/broll/src/templates/ItemCount.tsx` |
| BASE | `ITEM_COUNT_BASE` = 84 frames (2.8 s) |
| HERO | `ITEM_COUNT_HERO` = 78 |
| Default props (`itemCountDefaults`) | `{"from": 1, "to": 12, "label": "Items on your file"}` |
| Props type | `ItemCountProps`: `from: number`, `to: number` (1 to 24, one block per item), `label: string` (empty = no label), `durationInFrames?`, `showSafeZones?` |
| What it shows | A thick white tile holds a big count that rests on 1, then eases up to 12. Each time the number ticks, a small raised blue block rises out of its socket on the tile. A short label lands under the tile. No ring, no dots, no money. |
| Preview | `marketing/broll/previews/item-count.png` (frame 78) |
| MP4 | `marketing/broll/out/u4/item-count.mp4` (84 frames, 1080x1920, 30 fps) |

- **Timing:** the tile comes forward from frame 0. It holds on "1" with one block until frame 20. Then it counts up (tabular numbers, the kit's ease-out `countUp`), and each block rises the moment its number shows. The count reaches 12 at about frame 48. The label lands at 46. Everything is still by about frame 60.
- **Layout:** 12 items make 6 blocks by 2 rows. 1 to 6 items make one row. For 13 to 24 items the blocks shrink so the tile still fits (checked with 24).
- **Checked:** the defaults, 1 to 5, 1 to 24, no label, and a 60-frame length. All words stay inside y 269 to 1248.

**Script lines it serves (5 scripts):**

- $297 Ads 1, 3, 4 and 5: "Sometimes it's one item. Sometimes it's twelve."
- Ad 24: "Sometimes one item is holding it back, and sometimes it's twelve." For Ad 24, pass `"label": "Items holding it back"`, the words the 10-02 shot list already uses.
- The default label fits Ad 1 ("Everything on your file holding you back…"). For the other ads, take the label from the sentence just before the line. Example: Ad 4, "I'll name everything holding you back", gives "Items holding you back".
- The 13 hidden data points keep the HiddenDataPoints ring. This clip is only for "one or twelve".
