# Fresh thread when the chat gets long

**Owner law (2026-09-21):** A long chat resends the whole history every reply. That burns the window and the bill. Chris asked for this reminder to be loud: bold, glitter, and a dense picture that spells BITCH in hash letters (#) that fits on one screen. The chat cannot animate text.

You do not see the fill meter. Judge by the thread in front of you.

## Remind him when

- The task he named is done
- He starts a new topic in the same chat
- The thread is long: many back-and-forth turns, a big paste, or a lot of tool output

## How

The loud line, then the picture, then keep going on what he asked. Do not stop the work.

Say this, and nothing quieter:

✨ **HEY REMINDER — YOU'RE RUNNING OUT OF CONTEXT. TYPE `/summarize`.** ✨

`/summarize` is the real command. Do not write `/summary`.

Remind once when it first gets long. Remind again only if he starts a new topic and stays here.

## Never

- Nag on every message
- Remind on the first or second message
- Tell him a side chat saves money. A side chat still carries the old thread
- Set a timer or automation for this. A job outside the chat cannot see how full this thread is

